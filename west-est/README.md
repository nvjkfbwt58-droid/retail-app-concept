# WEST-EST

Рабочий редизайн публичного сайта westestminsk.by. Каталог перенесён 4 ноября 2026 года: **205 уникальных товаров, 14 категорий, 208 оригинальных фотографий продуктов**.

Сайт: https://nvjkfbwt58-droid.github.io/retail-app-concept/west-est/

## Публичный функционал

- Главная, весь каталог, все категории с исходными URL и 205 отдельных страниц товаров.
- Поиск по названию, артикулу и описанию; до 6 подсказок, ограничение поиска категорией.
- Сортировка по исходному порядку, популярности, дате, цене в обе стороны; добавлена сортировка по алфавиту.
- Сетка 2/3/4 колонки и список на компьютере, адаптивная сетка на телефоне.
- Пагинация по 12 товаров; фильтры и страницы сохраняются в URL.
- Быстрый просмотр, галереи, увеличение фотографий, раскрываемое описание, похожие товары.
- Телефоны, email, Telegram и карта склада Google Maps с загрузкой по нажатию.
- Дополнительные страницы производителей и сотрудничества для бизнеса.

На исходном сайте нет публичных корзины, оформления заказа, онлайн-оплаты, аккаунтов или контактной формы. Нулевые значения цены в WooCommerce являются техническими: настоящих цен на исходном сайте не показано. В редизайне цены не выдуманы, предусмотрен переход к менеджеру.

## Производительность

Чистые HTML/CSS/JavaScript, без React, библиотек и сборки на устройстве посетителя. Все 251 содержательная страница предварительно сгенерирована. Основной контент и переходы работают без JavaScript. Поиск и быстрый просмотр загружают локальный индекс 98 КБ по необходимости. Шрифты размещены локально, изображения WebP с двумя размерами, `loading=lazy` за пределами первого экрана. Карта и внешние скрипты не загружаются до действия пользователя. На главной нет аналитики или сторонних виджетов.

Первый экран: герой 132 КБ на компьютере и 44 КБ на небольшом экране. Скорость фактического открытия зависит от подключения посетителя и ответа GitHub Pages.

## Запуск и изменение

Готовую статическую версию можно взять из `west-est/` ветки `gh-pages`. В рабочем проекте она находится в `dist/`:

```sh
python3 -m http.server 4173 --directory dist
```

Изменения:

- `src/styles.css`: визуальная система, адаптивная вёрстка.
- `src/app.js`: поиск, фильтры, диалоги, галереи.
- `scripts/build.py`: шаблоны и генератор всех страниц.
- `data/catalogue.json`: полный импорт каталога, исходные данные сохранены отдельно.
- `data/functional-audit.json`: проверенный перечень исходных функций.

Для пересборки достаточно Python 3, сторонние пакеты не требуются:

```sh
python3 -m pip install Pillow
python3 scripts/prepare_assets.py
python3 scripts/build.py
```

Обновление публичных данных с исходного сайта требует сети и Pillow:

```sh
python3 scripts/import_catalogue.py
python3 scripts/finalize_catalogue.py
python3 scripts/build.py
```

Необходимость обновления данных контролируется владельцем. Автоматическая синхронизация с WordPress и доступ к его частной админке не подключены. Это независимая опубликованная копия публичного каталога; исходный westestminsk.by не изменён.

## Содержание и происхождение

Названия, характеристики, статьи, номера телефонов, фотографии упаковок и категории взяты с исходного сайта. Если в описании исходного товара сведений нет, они не выдуманы. Артикул или марка, явно написанные в заголовке товара, могут также выводиться отдельным полем. Страны происхождения не выдаются за производителей на странице марок.

Главный натюрморт создан для визуального оформления; он не используется вместо фотографий конкретных товарных упаковок. У всех карточек товаров реальные изображения оригинального каталога.

## Публикация

Проект размещён отдельной папкой `west-est` в существующем репозитории `retail-app-concept`. Ветка `main` содержит исходники в `west-est/` и базовые фирменные ресурсы. Готовый сайт со всеми изображениями и страницами находится в ветке `gh-pages`, папка `west-est/`. GitHub Actions собирает его из зафиксированного каталога через `scripts/prepare_assets.py`, затем `scripts/build.py`. Старый концепт приложения сохраняет свой адрес.

Для другого адреса перед пересборкой замените константу `SITE` в `scripts/build.py`. Все внутренние пути относительные и поддерживают подкаталог GitHub Pages.
