# Просмотр и передача проекта

Макет: https://nvjkfbwt58-droid.github.io/retail-app-concept/

Ветка main содержит весь проект, изображения и документацию. Приложение находится в dist/ и не требует сборки или установки пакетов.

Локальный запуск:

```sh
python3 -m http.server 4173 --directory dist
```

Откройте http://localhost:4173/.

GitHub Pages публикуется из корня ветки gh-pages. Она содержит содержимое dist/ без дополнительной вложенности. После правок в main обновите файлы этой ветки из dist/.

Все действия в приложении демонстрационные. Реальной кассы, платежей и серверного учёта бонусов нет.
